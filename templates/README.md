# 成果物のフォーマット

顧客とFDEが、確認したこと、判断した理由、次に必要なことを共有するための型です。既存の設計書やチケットにも、同じ意味の項目を対応させて使えます。

| 業務 | 主に使う成果物 |
| --- | --- |
| [業務理解・対象選定](../work/discovery/README.md) | [業務課題・改善候補](discovery-brief.md)、[業務範囲](field-work/work-grain-record.md)、[現行業務の観察](field-work/case-observation-record.md) |
| [業務要件定義](../work/planning/README.md) | [業務要件](definition-brief.md)、[変更案](field-work/process-change-record.md)、[費用・効果](field-work/cost-benefit-record.md) |
| [協働設計](../work/design/README.md) | [ワークフロー](workflow-brief.md)、[委任範囲](field-work/delegation-record.md)、[外部接続](field-work/connection-requirements.md) |
| [実装・テスト](../work/implementation/README.md) | [実装引継ぎ](field-work/implementation-handoff.md)、[次工程への移行判断](delivery-review.md) |
| [PoC・導入評価](../work/evaluation/README.md) | [PoC計画・評価](ai-trial-brief.md)、[次工程への移行判断](delivery-review.md) |
| [導入・運用改善](../work/operations/README.md) | [体制・定着計画](team-adoption-brief.md)、[リスク・運用](field-work/risk-and-operation-record.md) |

全ての型を最初に埋める必要はありません。作業に必要なものを選び、不明な項目は確認先とともに残します。
