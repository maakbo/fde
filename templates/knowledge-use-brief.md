# 知識を使い、更新するための記録

必要な箇所から書き始める。未確認は未確認のまま、次に確かめる相手と問いを残す。

- 対象の仕事・判断／使う人:
- 元の根拠・位置・版／正式さを確認する担当:
- 判断の理由・条件／適用範囲／例外:
- 手順・入力・成果・完了／迷った時の戻り先:
- 使える人・環境・操作／未確認の利用条件:
- 状態（案・確認済み・廃止）／見直し担当ときっかけ:

| 質問・状況 | 期待する根拠・判断／確認者 | 取得した根拠と版 | 回答・行動の観測 | 問題の段階と修正先 |
| --- | --- | --- | --- | --- |
| 通常例 |  | 未実行 | 未実行 |  |
| 例外・不足・矛盾 |  | 未実行 | 未実行 |  |

- 次に返す具体的な問い:
- 変更した正本／索引・古いコピー・利用者への反映:
- 再確認の結果／残る不明／次の停止点:
