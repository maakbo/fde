# 情報と処理の対応

## 記入の区分

[共通の成果形式](../../work/references/artifact-contract.md)の対象/版・状態・根拠・未決・次の受渡しを保つ。

- **必須**：対象/入口出口/受取者/資料と許可、今回の処理または属性/参照単位/記録入力の該当表、根拠/欠損と返却、実施/未実施。
- **条件付き**：処理分担なら冒頭表、属性設計なら属性表、参照単位作成なら単位表、今後の記録入力なら項目/入力負担表。その作業に必要な版・同名異版・適用範囲・訂正の確認を残す。
- **任意**：選んでいない作業の節は理由付きで省略可。全節を一括記入しない。

不明は未確認と影響/確認先を残す。選んだ節の表列を維持し、該当しない節は理由付きで省略できる。既存記録は同義欄と対応を示して再利用する。
