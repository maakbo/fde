# チームで一件を試すための記録

既存IssueやProjectへ必要な部分を取り込む。空欄を本人に一括で埋めさせない。
架空回答、提案、実際に確認した合意・観測を区別する。

- 誰の仕事／次の受渡し／望む変化:
- 現状と根拠／今回の範囲・対象外／許可情報・環境:
- 今進められること／進められないこと:

| 人・役割 | 本人の言葉と守りたいこと | 根拠／仮説／確認待ち | 次に試す支援・担当 |
| --- | --- | --- | --- |
| 実行する人 |  |  |  |
| 受け取る・確認する人 |  |  |  |
| 判断・支援する人 |  |  |  |

| 受渡し・判断 | AIと通常ツールに任せること | 決定・実行・確認・停止・再開の担当 | 時間・権限・代替担当／未確認 |
| --- | --- | --- | --- |
|  |  |  |  |

- 共通ルールと現場の裁量／専門確認が要る例外:
- 支援の実態（相談先・時間・環境）／その確認者:
- 一件の練習（入力・根拠・版→依頼→確認・修正→次へ渡す）:
- 本人がやってみた結果／失敗・不明時の戻し先／必要な支援:

| 品質・利用・効果の観点 | baseline・対象機会・期間と確認者 | 目標/TBD・許容しない失敗 | 実際の観測／未測定 |
| --- | --- | --- | --- |
| 成果の品質・説明 |  |  |  |
| 利用できたか・しなかった理由 |  |  |  |
| 受渡し全体の時間・負担・手戻り |  |  |  |

詳細な比較は既存の試行評価記録へリンクし、二重に管理しない。

| 残る問い | 分かったことと限界 | 次の検証・担当／止める操作 |
| --- | --- | --- |
| 誤り／実運用／情報／費用／責任のうち重要なもの |  |  |

- 判断（準備のみ／限定試行／修正再試行／証拠待ち／停止）と根拠:
- 実際の開始判断者／開始条件／停止と従来手順への戻し:
- 更新・教育支援・共有の担当／次の観測と再判断のきっかけ:
