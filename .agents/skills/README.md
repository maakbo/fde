# FDEの作業Skill

各Skillは、AIエージェントが一つの作業に集中するための入力・手順・成果・完了条件を持ちます。人が業務を理解する入口は[FDEの仕事と業務](../../work/README.md)です。顧客にSkillの選択を求めず、FDEとエージェントが今必要なものを選びます。

| 業務 | 作業の選択と手順 |
| --- | --- |
| 業務理解・対象選定 | [現状の聞取り・業務図・課題の整理](../../work/discovery/workflow.md) |
| 業務要件定義 | [変更案・費用・効果・リスクの比較](../../work/planning/workflow.md) |
| 協働設計 | [役割・方式・情報・接続の設計](../../work/design/workflow.md) |
| 実装・テスト | [実装引継ぎ・処理・再開の設計](../../work/implementation/workflow.md) |
| PoC・導入評価 | [成功条件・品質・適用・次の判断](../../work/evaluation/workflow.md) |
| 導入・運用改善 | [体制・運用・知識更新・再評価](../../work/operations/workflow.md) |

複数の作業を進行する際は、[Discovery](discovery-facilitation/SKILL.md)、[業務要件定義](definition-facilitation/SKILL.md)、[ワークフロー設計](workflow-design-facilitation/SKILL.md)、[知識管理](knowledge-stewardship/SKILL.md)、[試行評価](ai-pilot-evaluation/SKILL.md)、[チームへの導入](team-adoption-facilitation/SKILL.md)を使います。前の成果と未解決を引き継ぎます。

業務の可視化には[業務モデリング](business-context-modeling/SKILL.md)と[業務フローの対話](business-flow-facilitation/SKILL.md)、仕組みの構成には[アーキテクチャ](architecture-modeling/SKILL.md)を使います。[Mermaid作成](mermaid-diagram-authoring/SKILL.md)、[明示依頼時の画像出力](mermaid-diagram-export/SKILL.md)、[読者向けレビュー](reader-facing-artifact-review/SKILL.md)が表現と確認を支えます。
