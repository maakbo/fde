# 一件の時間を担当別の人手・機械処理・待ちへ分け、効果比較に使える観測を作る

## 開始入力

対象業務の開始/終了、区間の時刻/担当/時間種別、件数/期間、観測か申告かの根拠。
今ある事実から仮説/下書きを返し、不足を優先して確認する。実際の権限・合意・観測を代作しない。

## 実行

1. 何の開始から終了かを揃え、各区間の担当/開始/終了/種別/重なり/欠測を記録する。架空時刻を実測とは呼ばない。
2. 人の能動作業、AI/機械処理、待ち、期間支援を分ける。処理中に人が別作業できるか未確認なら人手へ算入しない。
3. 担当別の人手とその総和、受領から受渡しまでの経過時間を別に計算する。重複区間を経過時間へ二重加算しない。
4. 月/日の支援を一件の経過へ足さない。一件から月へ外挿するには頻度/対象/ばらつき/例外を確認する。
5. 算術を検算し、分かる値と条件式/欠測を返す。長時間だけで低価値や自動化優先としない。変更案の測定も同じ開始/終了で行う。

## 成果と完了

[作業の記録](../../../templates/field-work/work-time-record.md)の必要な欄を使う。
時間種別/期間/担当が揃い、人手と経過が再計算でき、不明を0にしていない。
原理や手法の違いが判断に必要な時だけ[業務分析の判断](../../../guides/field-work/references/work-analysis-methods.md)を読む。
不一致や新条件は該当作業/判断者へ戻す。全様式の記入を開始条件にしない。
