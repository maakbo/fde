# テーマコンテキスト図：ゴールの見せ方

中央は白地の角丸四角と大きめの文字に統一。右上の文言と矢印なしの点線も揃え、コメントの見せ方だけを比べる。

## 1｜吹き出し

細い枠で囲む。点線はテーマに添えたコメントであることを示す。
