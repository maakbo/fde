# FDE

人、AI、システムが、それぞれの強みを活かして自然に協働できる。FDEは、そんな業務の仕組みを一緒につくります。

仕組みを誰かに任せきりにはしません。使う人たち自身が理解し、選び、変え、育てていけるところまでを仕事に含めます。
