# maakbo expression-production loop

This public example uses the three-rung context ladder with maakbo's own work
as the subject:

1. [Overall context](overview.md) — the title-level work and major actors.
2. [Use-case / scene context](context.md) — turning a loose idea into a first
   expression.
3. [Business flow](flow.md) — finding the core, drafting, and refining.

The [model-set index](model-set-index.md) links the parent/child trace and the
parallel [master maps](master-model-index.md). It is a working hypothesis for
discussion, not a claim that every maakbo practice has already been settled.
