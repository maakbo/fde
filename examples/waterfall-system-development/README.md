# PDF帳票作成システムの開発 — development-work evaluation

このevaluation sampleは、PDF帳票作成システムを開発する業務を題材に、13工程を会話するための
development-work modelを示します。実案件の事実ではなく、境界と要求を会話できるように置いた
syntheticな前提です。ここで扱う13工程は、RDRA domain modelの下位階層ではありません。

対象システムそのもののcurrent RDRA domain modelは、独立した[PDF帳票システム sample](../pdf-report-system/)
で確認してください。
