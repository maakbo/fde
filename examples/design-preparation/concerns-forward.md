**回答案版・状態:** 条件 C は CONCERNS-ANS-v1-C1、条件 D は CONCERNS-ANS-v1-D1。[初期回答](concerns-answers.md) の CONCERNS-ANS-v1（A1〜A5）を基準にした差分。これらは根拠資料の DEMO-v2 等とは別の回答案版。C と D はそれぞれ独立の別条件で、両方が同時に起きたものとして混ぜない。資料・発言はすべて架空で、対話・承認・実測ではない。

## 条件 C｜平均精度と確認ボタン

**追加根拠:** DEMO-v2 の架空ログは100件中99件問題なし、1件は根拠のない日付境界で訂正未完了。確認ボタンはあるが、確認資料へのアクセスと時間はない。QUALITY-v1 は変わらず、追加許可もない。

**相手へ渡す更新回答**

- **A1・設計担当役へ:** 前回は境界の検証が未確認でした。今は、架空ログに根拠のない日付境界が1件あり、訂正も終わっていません。QUALITY-v1 が禁じる正式仕様への受渡しを防げたとは言えません。資料と時間のない確認ボタンでは見つけて直す条件もありません。この1件の原因、差戻しと停止、確認に必要な正本・時間・権限を確かめるまで、全件を通す判断はできません。
- **A2・管理者役へ:** 「99%だから安全」とは説明できません。100件のうち、今回守るべき日付境界で未訂正の1件が出ています。先の6件は正常要件の文書照合で、DEMO-v2 と条件や分母が同じと分からないため106件中105件という集計もしません。許容できない誤りの扱いと条件を揃えた評価を決める前に、全体を通す説明・開始は待ちます。
- **A5・レビュー担当役へ:** 確認ボタンがあることは確認が成立する証拠ではありません。資料アクセスと時間がない現状で、根拠のない境界を見抜いて差し戻す役割を引き受けられるか、資料・権限・代替を確かめる必要があります。責任の法的結論は引き続き未確認です。

**変わった点と次の判断:** A1 は「境界の検証状況を確認できていない」から「未訂正の重大な架空例あり」へ、A2 は「一般化できない」に加えて「異なる条件の6件と100件を足せない」へ、A5 は確認手段の実効性に具体的な不足が加わった。A3 の経路・許可と A4 の費用条件は変わらない。設計・評価担当候補は当該1件の正本、出力、検出・訂正・停止の記録を照会し、QUALITY-v1 に照らして再評価する。資料アクセス、確認時間、権限を持つ確認者の実任命と、全件開始の許可は待つ。

## 条件 D｜経路図の報告と追加見積り

**追加根拠:** 情報管理担当役が保存先候補図に検索索引、モデル入力、出力、ログの4経路を描いたと報告。ただし図の実物、契約本文、社内送信許可、実制御は未提示。共同レビューは予定のみ。予算判断役への追加見積りは「下書き作成と確認だけなら月5時間の余力」。月8時間の支援仮説と費用未見積は変わらない。

**相手へ渡す更新回答**

- **A3・情報管理担当役へ:** 4経路を候補図に描いたという報告で、確認すべき場所は具体化しました。ただ、図の実物と各経路の送信先・保存・削除、契約、設定と実制御、社内の送信許可はまだ見ていません。共同レビューの予定は承認ではありません。実設計書の送信は待ち、まず図と証跡を照合する準備を進めます。
- **A2・管理者役へ:** 共同レビューの予定だけでは、週末から実設計書で始める許可になりません。経路図の実物、契約と実制御、社内送信許可を確認し、試行の開始権限者と停止条件を決める必要があります。今回できるのはレビュー資料と質問の準備までです。品質については DEMO-v1 の範囲を超えていません。
- **A4・予算判断役へ:** 同じ月の前提で下書き作成と確認を合わせた余力が5時間という追加見積りは、元の10時間減－5時間増と算術上は一致します。支援8時間を含めると、差し引き月3時間の負担増という仮説です。利用料・導入費と現金支出の変化が未見積なので、年間ROIや投資効果はまだ確定できません。

**変わった点と次の判断:** A3 は経路候補が4つと報告されたが、実物と制御は未確認。A2 は週末開始の意向が出たが、許可は増えていない。A4 は作成＋確認の純時間が月5時間という同じ前提の見積りが追加され、支援を含む結論は変わらない。A1 と A5 の品質・権限条件も変わらない。情報管理担当候補は図の実物、保存・削除、契約・設定・実制御、社内許可を照会し、開始権限者が送信可否を判断する。予算担当候補は同じ対象・期間の全費用と純便益を照合する。週末開始、実データ送信、支出は待つ。
